# 桌宠项目 - Desktop Pet

一个可爱的 2D 桌面宠物，帮你管理桌面文件！

## 功能

- ✅ 2D 可爱形象（可拖动）
- ✅ 左键拖动 / 双击打开助手
- ✅ 右键菜单快捷操作
- ✅ 语音识别交互
- ✅ 文件/文件夹增删改查
- ✅ 二次确认机制

## 快速开始

### 方法 1：一键安装

双击 `install.bat`

### 方法 2：手动安装

```bash
cd D:\桌宠
pip install -r requirements.txt
python main.py
```

## 使用说明

### 鼠标操作
- **左键拖动** - 移动桌宠位置
- **左键双击** - 打开助手对话框
- **右键点击** - 显示快捷菜单

### 语音命令
- "打开 [文件名]" - 打开文件或程序
- "创建 [文件名]" - 创建新文件
- "删除 [文件名]" - 删除文件（会二次确认）
- "移动 [文件名] 到 [位置]" - 移动文件
- "查看 [文件名]" - 查看文件信息

### 文字命令
在助手对话框中输入命令后回车

## 技术栈

- Python 3.8+
- PyQt5 - GUI 界面
- SpeechRecognition - 语音识别
- 2D 形象绘制

## 项目结构

```
桌宠/
├── main.py              # 主程序入口
├── desktop_pet.py       # 桌宠核心（2D 形象 + 交互）
├── file_manager.py      # 文件管理器
├── voice.py             # 语音处理
├── config.json          # 配置文件
├── requirements.txt     # 依赖列表
├── install.bat          # 安装脚本
├── run.bat              # 快速启动
└── README.md           # 说明文档
```
